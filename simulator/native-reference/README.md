# 이전 네이티브 시뮬레이터 참고 코드

최신 0.5.2 [차량 앱·웹 시뮬레이션 원본 캡처](../../README.md) · [현재 여섯 여정 검증](../../captures/web/0.5.2/verification.json). 이 폴더는 보관 자료이며 최신 실행 화면의 출처가 아니다.

이 폴더는 방향 수정 전의 시뮬레이션 화면과 이전 트렁크 시연 UI를 보관한다. Android 제품/시험 source set에 연결되어 있지 않다.

최신 사용자 요구는 ‘핵심 차량 기능 유지, 시뮬레이션 분리’다. 이 코드를 제품 APK의 화면으로 다시 연결하지 않는다. 기존 웹 시뮬레이터는 ../index.html에서 별도로 실행한다. 자동 시험용 경로와 엔진은 app/src/androidTest 및 app/src/testSupport에 있다.
