# 0.5.1 — 회사 PC에서 가능한 안정성 수정

2026-10-30 KST. `integration`에서 수정하고 `apk` / `simulation`으로 공통 변경을 반영합니다. main 제품 코드는 승격하지 않습니다.

## 변경

- GPS 갱신: 사진은 여정 상태에 유지하고 현재 위치에 대한 공유 확인만 무효화합니다. 새 여정에서는 사진을 비웁니다. 사진 URI는 영구 저장하지 않으며 프로세스 복구 때 다시 선택합니다.
- 사진 선택 취소: 기존 사진과 확인 상태를 유지합니다. 새로운 선택만 확인을 해제합니다. 이전 여정에서 열었던 선택기의 결과나 주행 중 돌아온 선택 결과는 적용하지 않습니다. 최대4장, 중복 제거. 화면에 첨부 전체 제거 기능 추가.
- 하차 지점: 추천 선택과 직접 선택이 같은 규칙을 사용합니다. 남은 ETA/거리/경과 시간/주문을 유지합니다. 베이 변경만으로 관측된 장애물을 없애지 않습니다.
- 초기화: 수령 전 진행 중 주문은 초기화로 지우지 못합니다. 명시적 취소 또는 수령 후 새 여정을 시작합니다. 외부 시험 초기화는 명시적 취소를 먼저 수행하도록 수정했습니다.
- 음성: 같은 안내를 다시 요청해도 읽도록 재생 이벤트를 구분합니다. 인식 내용이 없는 취소/실패에서는 기존 메뉴와 주문을 유지하며 안내합니다.
- 데이터: APK `MobilityModels.kt`의 목적지3곳/메뉴5개를 `scripts/export-studio-catalog.py`로 웹 목업의 `catalog.js`에 생성합니다. 초 단위를 명시하고 화면에서 분으로 변환합니다. `--check`로 불일치를 검출하며 빌드·목업 검사에 연결했습니다. 동일 목적지·메뉴의 ETA/가격/조리/배달 시간이 일치합니다.

기존 도로 주행 시뮬레이터 `simulator/`의 식사 시연은 압축된 초 단위 가상 시간 모델입니다. 이번 데이터 통일 대상은 차량 앱과 `release/studio/` 웹 UI 목업입니다. 주행 시뮬레이션의 시간 축을 앱과 실시간 동기화하는 기능은 아직 미구현입니다.
